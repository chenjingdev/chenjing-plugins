# CUA Bar가 설치·점검·업데이트를 모두 맡기
## 목적
앱 하나만 깔면 Claude Code에서 CUA를 쓰게 한다. MCP·스킬의 설치와 제거, 환경 점검, 새 판 업데이트를 CUA Bar가 모두 맡고 Claude 플러그인은 따로 깔지 않는다. 사용자 원문(2026-10-21): "어짜피 앱이 그 역할 하니까 그냥 앱에서 바로 mcp설치 시키면 되지 않나?", "mcp랑 스킬 설치시키고 지울때도 앱에서 삭제시키게 하고. 잘 환경셋팅 됐는지 검토하는것도 앱에서 하고", 자동 업데이트 제안에 "ㅇㅇ".
## 범위
CUA Bar 앱(`apps/cua-bar`), 앱에 담을 연결 엔진(지금의 `plugins/cua`), 받는 곳(cua.chenjing.org), README, 옛 CUA 도구 이름을 쓰는 pact 플러그인 세 파일.
## 하지 않는 것
- Claude 플러그인과 마켓플레이스로 나눠 주는 길. 플러그인이 없어지면 앱 없이 MCP를 깔 길도 없어서, 같은 날 정한 '앱 없이 setup.sh 한 줄'도 없앤다 [AI 가정]
- 다른 기기의 0.7.0을 옮기는 코드. 아직 배포 전이라 이 맥만 손으로 옮긴다.
- 다음 판 후보: 업데이트 되돌리기(옛 판으로 돌아가기)
## 기능
- F1 앱이 Claude Code에 cua MCP와 cua 스킬을 직접 깐다 [사용자]
  - 케이스: Claude Code나 Codex가 없음 → 그 줄만 점검에 보이고 미룬다. 나중에 생기면 다음 점검에서 한 번 깐다
  - 케이스: 앱이 깔지 않은 cua MCP·스킬이나 옛 cua 플러그인이 있음 → 건드리지 않고 점검에 충돌과 지우는 방법을 보인다
- F2 앱의 제거가 MCP와 스킬도 지운다 [사용자]
  - 케이스: 래퍼로 켠 Codex 호스트가 살아 있음 → 지금처럼 정상 종료 뒤 다시 하라고만 하고 아무것도 바꾸지 않는다
- F3 앱이 환경을 항목마다 점검해 '점검' 탭에 한 줄씩 보인다: Claude Code, MCP, 스킬, 엔진, 파이썬 환경, Codex 래퍼와 로그인 설정, 중계기, 앱 로그인 항목, Codex 호스트와 연결 시험 [사용자]
  - 케이스: 깨진 줄 → 상태 카드에 오른 문제는 카드에서 고치고 그 줄은 "위 카드에서 고쳐요"만, 카드에 안 오른 줄은 그 줄에서 고친다
  - 케이스: Codex가 꺼져 있음 → 연결 시험을 건너뛰고 "Claude 대화를 열면 켜져요"라고만 한다
- F4 새 판이 있으면 묻지 않고 받아 SHA-256과 서명 팀을 확인한 뒤 바꿔 끼우고 다시 켠다 [사용자]
  - 케이스: 받기·확인 실패나 앱 자리에 쓸 수 없음 → 지금 판을 그대로 두고 '새 버전' 버튼(받는 곳 열기)을 남긴다
  - 케이스: 다시 켜진 새 판 → 엔진·MCP·스킬을 새 판으로 맞추고 연결 시험을 한 번 한 뒤, 새 Claude 대화부터 쓰인다고 한 번 알린다
## 공통 규칙
- R1 앱은 켜질 때 묻지 않고 MCP·스킬·엔진을 깔고, 빠지거나 판이 다르면 다시 깐다 — 앱을 깐 것이 곧 CUA를 쓰겠다는 뜻이라 [AI 가정]
- R2 엔진은 앱 안에 담고 판마다 `~/.local/share/codex-cua/engine/` 아래 판 번호 폴더에 풀어 MCP와 Codex 래퍼가 그 사본을 쓴다. 옛 판 사본은 쓰는 프로세스가 없을 때 지운다 — 업데이트로 앱이 바뀌어도 열린 Claude 대화와 켜진 Codex의 연결이 끊기지 않게 [AI 가정]
- R3 MCP는 `claude mcp add -s user`와 `remove`로만 바꾸고, 스킬은 `~/.claude/skills/cua/`에 앱이 깐 표식과 함께 둔다. 점검은 `~/.claude.json`과 그 폴더를 읽기만 한다 — `claude mcp list`는 서버를 띄워 시험하고, 사용자가 따로 둔 설정은 건드리지 않게 [AI 가정]
- R4 앱은 Codex를 대신 끄지 않고 포커스를 뺏지 않는다. 다시 켜기는 지금처럼 사용자가 누를 때만 한다 [사용자]
- R5 GitHub push·릴리스와 받는 곳 배포는 할 때마다 묻고, 지금은 배포하지 않는다 [사용자]
- R6 pact 플러그인이 쓰는 CUA 도구 이름을 새 이름 `mcp__cua__js`로 고친다 — 고치지 않으면 옛 플러그인을 지운 뒤 pact 검수가 말없이 화면 없이 돈다 [AI 가정]
