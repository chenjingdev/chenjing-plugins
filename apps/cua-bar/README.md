# CUA Bar

Codex를 평소처럼 켜도 Claude가 CUA(화면 조작)로 바로 붙게 하고, 메뉴 막대에서 상태를 보고, AI가 정리 없이 끝나며 남긴 브라우저 점유를 풀어 주는 맥 메뉴 막대 앱이에요. 이름은 가칭이에요.

앱은 `cua` 플러그인(`cua@chenjing-plugins`)이 만든 `codex-cua` 명령을 부르고, 돌려받은 것을 보여 줄 뿐이에요. 연결 자체는 플러그인이 해요.

Apple Silicon Mac, macOS 14 이상에서 돌아요. 앱 판 번호는 플러그인 판 번호와 늘 같아요.

## 받아서 켜기

1. [GitHub Releases](https://github.com/chenjingdev/chenjing-plugins/releases)에서 `CUABar-v<판>-macos-arm64.zip`을 받아요. 이 저장소에는 다른 것의 릴리스도 있으니, 앱은 태그가 `cua-bar--v<판>`인 것을 찾으세요.
2. 압축을 풀면 `CUABar.app`이 나와요. 이것을 Applications(응용 프로그램) 폴더로 옮겨요. 홈 폴더 안의 `~/Applications`도 돼요.
3. (선택) 파일이 온전한지 보려면, 받은 폴더에서 `shasum -a 256 -c SHA256SUMS.txt`를 실행해요. `OK`가 나오면 돼요.
4. `CUABar.app`을 열어요. 메뉴 막대에 아이콘이 하나 생겨요.

### 처음 열 때: 공증 안 된 앱

이 앱은 ad-hoc 서명만 했고 Apple 공증은 받지 않았어요. agent-bar와 같아요. 그래서 처음 열 때 macOS가 "확인되지 않은 개발자의 앱"이라며 막을 수 있어요.

- 앱을 한 번 열어 보고 막히면 닫아요.
- 시스템 설정 → 개인정보 보호 및 보안으로 가요. 아래쪽에 CUABar가 막혔다는 줄이 있어요. 그 옆의 **그래도 열기**를 누르고, 암호나 Touch ID로 확인해요.
- 터미널이 편하면 이렇게 해도 돼요: `xattr -dr com.apple.quarantine /Applications/CUABar.app`

한 번 열고 나면 다음부터는 묻지 않아요.

## 처음 켜면 일어나는 일

1. **연결을 저절로 설정해요.** Claude 플러그인은 깔려 있는데 `~/.local/bin/codex-cua`가 없거나 이 플러그인 것이 아니면, 앱을 켤 때 한 번 플러그인의 `setup.sh setup`을 저절로 돌려요. 파이썬 구성 요소를 받느라 몇 분 걸릴 수 있고, 그동안 상태 카드가 "연결을 설정하는 중"이라고 말해요. 실패하면 카드에 "연결 설정에 실패했어요"와 **다시 하기** 버튼이 떠요. 저절로 하는 것은 앱을 켠 한 번뿐이고, 그 뒤는 버튼을 누를 때만 해요.
2. **플러그인이 없으면** 카드의 **설치** 버튼으로 깔아요. 앱이 Claude Code의 `claude plugin` 명령으로 저장소를 더하고, 플러그인을 사용자 범위로 깔고, 이어서 연결을 설정해요. 끝나면 "새 Claude 대화부터 CUA가 붙어요"라고 알려요. 이미 열려 있는 Claude 대화에는 붙지 않아요. Claude Code가 없으면 "Claude Code가 없어요"라고만 말해요.
3. **로그인할 때 저절로 떠요.** Applications나 `~/Applications`에서 처음 열 때 한 번만 로그인 항목으로 등록해요. 그 뒤로는 다시 등록하지 않아요. 끄고 싶으면 시스템 설정 → 일반 → 로그인 항목에서 끄면 되고, 앱이 그것을 존중해요. 앱 안에는 스위치가 없어요. 지금 상태는 기록 탭 맨 아래 줄에 적혀요.
4. **Codex를 한 번 다시 켜야 해요.** 이미 켜져 있던 Codex는 연결 없이 켜진 것이라, 카드가 "Codex가 연결 없이 켜져 있어요"라고 하고 **다시 켜기**를 보여요. 앱은 누르기 전에는 Codex를 끄지 않아요. 누르면 "하던 Codex 작업이 끊겨요"라고 한 번 묻고, 정상 종료(강제 종료 없음)한 뒤 다시 켜요. 그 뒤로는 Dock이나 Spotlight로 켜도 Claude가 바로 붙고, Codex가 꺼져 있으면 Claude 대화를 열 때 뒤에서 켜져요.

## 화면

**아이콘**은 하나이고, 모양으로 구분해요: 준비(체크가 든 원), 작업 중(도는 화살표), 문제(경고 삼각형, 주황색). 올려 두면 한 줄 요약이 떠요. 누르면 팝오버가 열려요.

**상태 카드**는 맨 위에 있어요. 지금 상태, 한 줄 제목, "다음에 할 일", 그리고 문제일 때만 고치는 버튼이 하나 있어요.

| 문제 | 버튼 | 누르면 |
|---|---|---|
| Codex 앱이 없어요 | 받는 곳 열기 | Codex를 받는 페이지를 브라우저로 열어요 |
| CUA 플러그인이 없어요 | 설치 | 위 "처음 켜면 일어나는 일" 2번 |
| 앱과 플러그인 판이 달라요 | 맞는 판 받기 | 플러그인이 앱보다 낮으면 플러그인을 갱신하고 연결을 다시 설정해요. 플러그인이 앱보다 높으면(마켓플레이스가 저절로 갱신한 경우) 새 앱 판을 받는 곳을 열어요 |
| 연결 설정이 안 됐거나 깨졌어요 | 고치기 (한 번 실패한 뒤에는 다시 하기) | `setup`을 다시 돌려요 |
| Codex가 연결 없이 켜져 있어요 | 다시 켜기 | 한 번 묻고, 정상 종료한 뒤 다시 켜요 |
| 끝난 연결이 남아 있어요 | 놓아주기, 놓아 본 뒤에는 끝난 연결 끄기 n | 먼저 끝난 연결이 잡은 브라우저 점유를 풀어요. 놓아준 연결도 그 런타임이 살아 있는 동안은 끝난 연결로 남아요. 그래서 이번에 앱을 켠 뒤 끝난 연결을 모두 놓아 봤으면 버튼이 **끝난 연결 끄기 n**으로 바뀌고, 누르면 몇 개를 끄는지 한 번 물은 뒤 꺼요 |
| 점유가 남았을 수 있어요 | 놓아주기 | 주인이 사라진 점유를 세션으로 콕 집어 풀어요 |
| CUA 상태를 읽지 못했어요 | 다시 읽기 | 상태를 다시 읽어요 |

그 아래에 탭이 네 개 있어요.

- **연결**: Claude와 Codex가 붙은 연결 목록이에요. 줄마다 작업 폴더, 시작 시각, 메모리, 상태(사용 중 · 쉼 n분 · 끝남 · 알 수 없음)가 보여요. 줄의 버튼: **놓아주기**(그 연결이 잡은 브라우저 탭만 놓아요. 연결은 그대로예요), **끄기**(탭을 놓은 뒤 정상 종료해요), **강제 종료**(그래도 안 꺼질 때만 써요). 아래의 **전체 끄기 · Claude만 · Codex만**은 몇 개를 끄는지 보여 주고 한 번 물어요. 이 묶음 종료는 Claude와 Codex 연결만 끄고, cmux-cua 같은 다른 도구는 건드리지 않아요. **끝난 연결 놓아주기**는 끝난 연결의 점유만 한꺼번에 풀어요.
- **브라우저 점유**: 주인이 사라진 점유("점유가 남았을 수 있음")예요. **콕 집어 풀기**는 그 세션의 점유만 풀어요. 안 풀리면 "막힌 탭 닫기"를 먼저, 그래도 안 되면 "확장 껐다 켜기"를 안내해요. 확장을 껐다 켜면 끊길 연결의 목록도 같이 보여요.
- **다른 도구**: 지금 화면을 쓰는 연결, 그리고 cmux-cua 같은 다른 도구의 상태예요. cmux-cua는 AI 대화마다 붙은 연결(`cmux-cua mcp`)이 한 줄씩 보이고, 줄마다 **끄기**가 있어요. 끄기는 그 연결만 정상 종료하고, 그 대화의 cmux-cua 도구는 다시 붙을 때까지 끊겨요. 띄운 AI가 사라진 연결은 "주인 없는 연결"로 맨 아래에 보여요. 정상 종료가 시간 안에 안 끝나면 **강제 종료**가 생기고, 누르면 한 번 물어요. cmux-cua 본체와 AI 앱은 끄지 않고, 묶음 끄기에도 들어가지 않아요.
- **기록**: 최근 조작(시각 · 에이전트 · 폴더 · 도구 · 성공 여부 · 걸린 시간)이에요. **진단 복사**는 붙여 넣어도 안전한 진단 글을 복사하고, 끝에 앱 판과 로그인 항목 상태 줄을 덧붙여요.

탭이 비어 있으면 "연결 없음", "점유 없음"처럼 한 줄로 말해요.

**맨 아래 줄**에는 상태를 읽은 시각, 새 판이 있을 때만 **새 버전 x.y.z**, **제거**, **끝내기**가 있어요.

AI가 정리 없이 끝나면 앱이 끝난 연결의 점유를 대신 놓아줘요. 알림은 세 가지뿐이에요: 연결 없이 켜진 Codex를 다시 켤지 묻는 알림(**다시 켜기** 버튼이 있어요), 주인이 사라진 점유가 1분 넘게 안 풀렸다는 알림(점유마다 한 번), 새 앱 판 알림(판마다 한 번). 알림을 꺼 두었으면 아이콘과 상태 카드에만 보여요.

## 새 판

앱을 켤 때 마지막 확인이 하루 넘었으면 곧바로, 그 뒤로는 하루에 한 번 GitHub Releases 목록을 읽어요. 태그가 정확히 `cua-bar--v<숫자>.<숫자>.<숫자>`인 정식 릴리스(초안과 시험판 제외) 가운데 가장 높은 판을 찾고, 지금 앱보다 높으면 **새 버전 x.y.z** 버튼이 떠요. 누르면 그 릴리스 페이지를 열어요. 판마다 한 번 알림도 보내고, 알림을 누르면 창이 열려요. 앱이 스스로 받거나 바꾸지는 않아요. 받아서 Applications에 덮어 넣으면 돼요.

확인이 실패하면 아무 말도 하지 않고 마지막 결과를 그대로 두어요.

## 지우기

팝오버 맨 아래의 **제거**를 눌러요.

1. 먼저 한 번 물어요: "연결 설정과 중계기를 되돌려요. Codex는 다음에 켤 때부터 연결 없이 원래대로 켜져요."
2. 확인하면 `codex-cua uninstall`을 돌려서 연결 설정과 중계기를 되돌리고, 로그인 항목을 풀고, 결과를 보여 준 뒤 앱이 꺼져요. `codex-cua`가 없거나 이 플러그인 것이 아니면 플러그인의 `setup.sh uninstall`을 대신 돌려요. 되돌릴 것이 하나도 없었으면 "되돌릴 연결 설정이 없었어요"라고 해요.
3. Codex가 켜져 있어서 되돌릴 수 없으면 "Codex를 정상 종료한 뒤 다시 해 주세요"라고만 하고 아무것도 바꾸지 않아요. 앱은 Codex를 끄지 않아요.

**남는 것**은 Claude 플러그인과 앱 파일이에요. 앱 파일은 휴지통으로 옮기면 돼요. 플러그인까지 지우려면 Claude Code에서 따로 지워요.

앱을 지우거나 꺼도 Codex는 깨지지 않아요. 연결은 앱이 아니라 플러그인과 `codex-cua`가 맡으니까, 앱이 없어도 Codex는 평소처럼 켜지고 Claude도 붙어요. 앱을 끄면 상태 보기와 자동 정리만 멈춰요.

## 개인정보

- 기록과 진단 복사에는 화면, 요청 내용, 시크릿이 들어가지 않아요. 시각, 연결, 도구 이름, 성공 여부, 걸린 시간만 있어요. 이 맥 밖으로 보내지 않아요.
- 앱이 직접 인터넷을 쓰는 곳은 하루 한 번 GitHub 릴리스 목록을 읽는 것 하나예요. 토큰도 계정도 없이 읽고, 보내는 것은 고정된 이름표 하나뿐이에요. 플러그인을 받거나 갱신할 때는 Claude Code가, 연결을 설정할 때는 플러그인의 설치 스크립트가 필요한 것을 받아 와요. 앱은 그 결과의 한 줄 요약만 보여 줘요.
- 앱이 저장하는 것은 마지막 새 판 확인 시각과 결과, 이미 알린 새 판 번호, 메뉴 막대 아이콘 위치, 처음 켰을 때 로그인 항목을 등록했다는 표시뿐이고, `~/Library/Preferences/dev.chenjing.cua-bar.plist`에 있어요.

## 개발하는 사람에게

```bash
cd apps/cua-bar
swift build && swift test          # 화면이 있는 로그인 세션이 필요해요
./scripts/build-app.sh             # CUABar.app을 만들고 ad-hoc 서명해요
./scripts/build-app.sh --install   # ~/Applications에 넣어요
./scripts/package-release.sh       # dist/에 zip과 SHA256SUMS.txt를 만들어요
```

- `--install`은 있던 앱과 설정을 `~/Library/Application Support/CUABar/Backups/<시각>/`에 백업하고, 앱이 켜져 있으면 멈추고, 복사본의 서명을 확인한 뒤에 바꿔요.
- `package-release.sh [폴더]`는 `build-app.sh`로 앱을 만들고 `CUABar-v<판>-macos-arm64.zip`(`ditto -c -k --keepParent`)과 `SHA256SUMS.txt`를 폴더에 써요. 기본 폴더는 `apps/cua-bar/dist/`이고 git이 보지 않아요. 합이 맞는지, 압축을 푼 앱의 서명이 맞는지까지 확인한 뒤, 태그 `cua-bar--v<판>`과 실행할 `gh release create ...` 명령을 **출력만** 해요. 태그를 만들거나 올리거나 `gh`를 부르지 않아요. 올리는 것은 그때그때 물어보고 직접 해요.
- 앱 판 번호는 `plugins/cua/.claude-plugin/plugin.json`의 `version`에서 와요.
