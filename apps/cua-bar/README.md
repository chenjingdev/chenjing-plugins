# CUA Bar

Codex를 평소처럼 켜도 Claude가 CUA(화면 조작)로 바로 붙게 하고, 메뉴 막대에서 상태를 보고, AI가 정리 없이 끝나며 남긴 브라우저 점유를 풀어 주는 맥 메뉴 막대 앱이에요. 이름은 가칭이에요.

앱은 `cua` 플러그인(`cua@chenjing-plugins`)이 만든 `codex-cua` 명령을 부르고, 돌려받은 것을 보여 줄 뿐이에요. 연결 자체는 플러그인이 해요.

Apple Silicon Mac, macOS 14 이상에서 돌아요. 앱 판 번호는 플러그인 판 번호와 늘 같아요.

## 받아서 켜기

받는 곳은 https://cua.chenjing.org 예요. 셋 중 편한 것으로 깔아요.

- **브라우저로 받기**: https://cua.chenjing.org/download 를 열면 dmg가 받아져요. dmg를 열고 `CUABar.app`을 Applications(응용 프로그램) 폴더로 끌어 놓은 뒤 열어요. 홈 폴더 안의 `~/Applications`도 돼요.
- **터미널 한 줄**: `curl -fsSL https://cua.chenjing.org/install.sh | sh`. 최신 dmg를 받아 SHA-256과 서명한 팀을 확인하고, `/Applications`(쓸 수 없으면 `~/Applications`)에 깐 뒤 켜요. 이미 같거나 새 판이 있으면 받지 않고 켜기만 해요. 켜져 있던 옛 판은 끄고 바꿔요.
- **에이전트에게 맡기기**: "CUA Bar를 설치해 줘. https://cua.chenjing.org/install"이라고 말하면 돼요. 그 주소는 에이전트가 읽는 설치 안내예요.

같은 파일은 [GitHub Releases](https://github.com/chenjingdev/chenjing-plugins/releases)에도 있어요. 태그가 `cua-bar--v<판>`인 릴리스의 `CUABar-v<판>-macos-arm64.dmg`예요. 파일이 온전한지 보려면 받은 폴더에서 `shasum -a 256 -c SHA256SUMS.txt`를 실행해요. `OK`가 나오면 돼요.

### 처음 열 때

앱과 dmg는 Developer ID로 서명했고 Apple 공증을 받았어요. 그래서 처음 열 때 macOS가 "인터넷에서 다운로드한 앱"이라며 한 번 물어요. **열기**를 누르면 되고, 다음부터는 묻지 않아요. 터미널 한 줄로 깔았으면 이 질문도 없어요.

## 처음 켜면 일어나는 일

1. **연결을 저절로 설정해요.** Claude 플러그인은 깔려 있는데 `~/.local/bin/codex-cua`가 없거나 이 플러그인 것이 아니면, 앱을 켤 때 한 번 플러그인의 `setup.sh setup`을 저절로 돌려요. 파이썬 구성 요소를 받느라 몇 분 걸릴 수 있고, 그동안 상태 카드가 "연결을 설정하는 중"이라고 말해요. 실패하면 카드에 "연결 설정에 실패했어요"와 **다시 하기** 버튼이 떠요. 저절로 하는 것은 앱을 켠 한 번뿐이고, 그 뒤는 버튼을 누를 때만 해요.
2. **플러그인이 없으면** 카드의 **설치** 버튼으로 깔아요. 앱이 Claude Code의 `claude plugin` 명령으로 저장소를 더하고, 플러그인을 사용자 범위로 깔고, 이어서 연결을 설정해요. 끝나면 "새 Claude 대화부터 CUA가 붙어요"라고 알려요. 이미 열려 있는 Claude 대화에는 붙지 않아요. Claude Code가 없으면 "Claude Code가 없어요"라고만 말해요.
3. **로그인할 때 저절로 떠요.** Applications나 `~/Applications`에서 처음 열 때 한 번만 로그인 항목으로 등록해요. 그 뒤로는 다시 등록하지 않아요. 끄고 싶으면 시스템 설정 → 일반 → 로그인 항목에서 끄면 되고, 앱이 그것을 존중해요. 앱 안에는 스위치가 없어요. 지금 상태는 기록 탭 아래쪽, 진단 복사 버튼 줄 바로 위에 적혀요.
4. **Codex를 한 번 다시 켜야 해요.** 이미 켜져 있던 Codex는 연결 없이 켜진 것이라, 카드가 "Codex가 연결 없이 켜져 있어요"라고 하고 **다시 켜기**를 보여요. 앱은 누르기 전에는 Codex를 끄지 않아요. 누르면 "하던 Codex 작업이 끊겨요"라고 한 번 묻고, 정상 종료(강제 종료 없음)한 뒤 다시 켜요. macOS가 CUA Bar가 Codex를 제어하려 한다고 물으면 **허용**을 눌러요. 종료 요청이 그 권한으로 가요. Codex가 종료를 한 번 더 물으면(예약 작업이 있으면 Codex가 물어요) Codex 창에서 **종료**를 눌러 주세요. 그동안 카드가 꺼지기를 기다린다고 말하고, 10분 안에 꺼지면 앱이 Codex를 다시 켜요. 그 뒤로는 Dock이나 Spotlight로 켜도 Claude가 바로 붙고, Codex가 꺼져 있으면 Claude 대화를 열 때 뒤에서 켜져요.

## 화면

**아이콘**은 하나이고, 모양으로 구분해요: 준비(체크가 든 원), 작업 중(도는 화살표), 문제(경고 삼각형, 주황색). 올려 두면 한 줄 요약이 떠요. 누르면 팝오버가 열려요.

**상태 카드**는 맨 위에 있어요. 지금 상태, 한 줄 제목, "다음에 할 일"이 있고, 앱 전체에 문제가 있을 때만 고치는 버튼이 하나 있어요. 연결 하나의 문제(끝난 연결, 남은 점유)는 카드가 말만 하고, 누르는 버튼은 아래 목록 맨 위 그 줄에 있어요. 누를 곳은 늘 한 군데예요.

| 문제 | 버튼 | 누르면 |
|---|---|---|
| Codex 앱이 없어요 | 받는 곳 열기 | Codex를 받는 페이지를 브라우저로 열어요 |
| CUA 플러그인이 없어요 | 설치 | 위 "처음 켜면 일어나는 일" 2번 |
| 앱과 플러그인 판이 달라요 | 맞는 판 받기 | 플러그인이 앱보다 낮으면 플러그인을 갱신하고 연결을 다시 설정해요. 플러그인이 앱보다 높으면(마켓플레이스가 저절로 갱신한 경우) 새 앱 판을 받는 곳을 열어요 |
| 연결 설정이 안 됐거나 깨졌어요 | 고치기 (한 번 실패한 뒤에는 다시 하기) | `setup`을 다시 돌려요 |
| Codex가 연결 없이 켜져 있어요 | 다시 켜기 | 한 번 묻고, 정상 종료한 뒤 다시 켜요 |
| CUA 상태를 읽지 못했어요 | 다시 읽기 | 상태를 다시 읽어요 |

"끝난 연결이 남아 있어요"와 "점유가 남았을 수 있어요"에는 카드 버튼이 없어요. 카드가 그 줄의 버튼 이름으로 "목록 맨 위의 정리를 눌러 주세요"(남은 점유면 "목록 맨 위의 탭 풀기를 눌러 주세요")라고 말하고, 연결 탭 맨 위의 **손볼 것**에서 눌러요.

그 아래에 탭이 둘 있어요.

- **연결**: Claude, Codex, cmux-cua의 연결과 남은 브라우저 점유가 한 목록에 있어요. 맨 위에는 지금 화면을 쓰는 연결이 한 줄 보여요.
  - **손볼 것**: 끝난 연결, 주인이 사라진 점유, 주인 없는 cmux-cua 연결이 맨 위에 모여요. 줄마다 버튼이 하나예요. 끝난 연결과 주인 없는 cmux-cua 연결은 **정리**(탭을 풀고 남은 연결을 꺼요. 제때 안 꺼지면 강제로 꺼요), 남은 점유는 **탭 풀기**(그 세션이 남긴 점유만 풀어요)예요. 앱이 끌 수 없는 끝난 연결은 탭만 풀고 그 까닭을 줄에 적어요. AI가 이미 없어서 묻지 않아요. 연결이 아직 잡고 있는 세션은 그 줄의 버튼(끝난 연결은 정리, 살아 있는 연결은 탭 풀기)이 푸는 길이라서, 점유 줄을 따로 두지 않고 카드에도 세지 않아요(한 세션이 두 줄로 보이지 않게). 그 줄의 버튼을 누를 수 없을 때는 점유 줄이 남고 확장 초기화 안내가 열려요. 살아 있는 연결이 잡은 점유는 주인이 있으니 "점유가 오래 남았어요" 알림도 없어요. 정리가 연결의 탭을 풀고 그 놓아주기가 첫 물음에 확인되면 엔진이 그 세션을 죽은 다리 기록에서도 바로 지워요. 두 번째 물음에서야 확인되면 자동 정리가 이어서 세션 ID로 브라우저를 불러 풀고 지워서, 어느 쪽이든 점유가 남았을 수 있다는 줄이 되살아나지 않아요. 앱이 정리할 줄이 둘 이상이면 머리에 **모두 정리**가 생겨 한 번에 정리해요. 한 줄뿐이면 그 줄의 버튼만 있어요. Codex 대화가 남긴 점유는 그 줄의 탭 풀기로만 풀어요. Codex 대화는 다시 열 수 있어서, 넘겨주려고 남긴 탭까지 닫지 않으려고요.
  - **Claude · n**, **Codex · n**: 살아 있는 연결이에요. 줄마다 작업 폴더, 시작 시각, 메모리, 상태(사용 중 · 쉼 n분 · 알 수 없음)가 보여요. 버튼은 **탭 풀기** 하나예요. 그 AI가 잡은 브라우저 탭만 풀고, AI는 화면 도구를 계속 써요. 일하는 중이면 한 번 물어요. 앱은 살아 있는 AI의 연결을 끄지 않아요. 그만 쓰려면 그 AI 쪽에서 끄면 돼요.
  - **cmux-cua**: 켜져 있는지와, AI 대화마다 붙은 연결(`cmux-cua mcp`)이 한 줄씩 보여요. 살아 있는 연결은 보기만 하고, 띄운 AI가 사라진 연결만 손볼 것에서 정리해요. cmux-cua 본체와 AI 앱은 끄지 않아요.
  - 맨 아래 **브라우저 탭이 계속 막히면**: "막힌 탭 닫기"를 먼저, 그래도 안 되면 "확장 껐다 켜기"를 안내하고, 확장을 껐다 켜면 끊길 연결의 목록을 보여요. 하나씩 풀 방법이 없는 점유가 있거나, 탭 풀기가 확장 쪽 까닭으로 실패하면 펼쳐져요.
- **기록**: 최근 조작(시각 · 에이전트 · 폴더 · 도구 · 성공 여부 · 걸린 시간)이에요. 맨 아래에 가끔 쓰는 버튼이 모여 있어요. **진단 복사**는 붙여 넣어도 안전한 진단 글을 복사하고, 끝에 앱 판, 로그인 항목, 알림 상태 줄을 덧붙여요. Codex가 이미 끝난 대화의 스레드를 스스로 다시 켠 빈 런타임은 목록에 보이지 않고, 있으면 이 글에 "Codex가 다시 켠 빈 런타임 n개 · 메모리" 한 줄로만 들어가요(Codex가 곧 내려요). 알림을 보일 수 없을 때만 **알림 켜기**가 보여요. **앱 지우기…**는 아래 "지우기"를 보세요.

목록이 비어 있으면 "연결 없음", "기록 없음"처럼 한 줄로 말해요.

묻는 것과 결과는 누른 버튼 옆에 나와요. 일하는 연결의 탭 풀기는 그 줄 바로 아래에서, **다시 켜기**는 카드 아래에서, **앱 지우기…**는 그 버튼 자리에서 물어요. 결과는 누른 줄에 한 줄로 나와요. **모두 정리**의 결과는 손볼 것 머리 밑에, **진단 복사**의 결과는 그 버튼 바로 위에 나와요. 그사이 줄이 사라졌거나 다른 탭으로 옮겼으면 맨 위에 나와요.

**맨 아래 줄**에는 상태를 읽은 시각, 새 판이 있을 때만 **새 버전 x.y.z**, 그리고 **끝내기**가 있어요.

AI가 정리 없이 끝나면 앱이 끝난 연결의 점유를 대신 풀어 줘요. 알림은 세 가지뿐이에요: 연결 없이 켜진 Codex를 다시 켤지 묻는 알림(**다시 켜기** 버튼이 있어요), 주인이 사라진 점유가 1분 넘게 안 풀렸다는 알림(점유마다 한 번), 새 앱 판 알림(판마다 한 번). 알림을 꺼 두었으면 아이콘과 상태 카드에만 보여요. **알림 켜기**는 알림을 아직 허용하지 않았으면 macOS의 질문을 다시 띄우고(화면이 잠긴 동안 앱이 켜지면 macOS가 묻지 못해요), 꺼 두었으면 시스템 설정의 알림을 열어요. 알림 본문을 누르면 macOS가 CUA Bar를 앞으로 불러 창이 열려요. 그 창을 Escape 따위로 닫았는데 CUA Bar가 아직 앞이면 앱이 앞 자리를 직전에 쓰던 앱에게 돌려주고(그 앱이 이미 꺼졌으면 앞 자리를 내려놓아요), 바깥의 다른 앱을 눌러서 닫았으면 그 앱이 그대로 앞이에요. 메뉴 막대 아이콘으로 연 창은 앞 앱을 바꾸지 않으니 돌려줄 것도 없어요.

## 새 판

앱을 켤 때 마지막 확인이 하루 넘었으면 곧바로, 그 뒤로는 하루에 한 번 GitHub Releases 목록을 읽어요. 태그가 정확히 `cua-bar--v<숫자>.<숫자>.<숫자>`인 정식 릴리스(초안과 시험판 제외) 가운데 가장 높은 판을 찾고, 지금 앱보다 높으면 **새 버전 x.y.z** 버튼이 떠요. 누르면 그 릴리스 페이지를 열어요. 판마다 한 번 알림도 보내고, 알림을 누르면 창이 열려요. 앱이 스스로 받거나 바꾸지는 않아요. 받아서 Applications에 덮어 넣으면 돼요.

확인이 실패하면 아무 말도 하지 않고 마지막 결과를 그대로 두어요.

## 지우기

기록 탭 맨 아래의 **앱 지우기…**를 눌러요.

1. 먼저 한 번 물어요: "연결 설정과 중계기를 되돌려요. Codex는 다음에 켤 때부터 연결 없이 원래대로 켜져요."
2. 확인하면 `codex-cua uninstall`을 돌려서 연결 설정과 중계기를 되돌리고, 로그인 항목을 풀고, 결과를 보여 준 뒤 앱이 꺼져요. `codex-cua`가 없거나 이 플러그인 것이 아니면 플러그인의 `setup.sh uninstall`을 대신 돌려요. 되돌릴 것이 하나도 없었으면 "되돌릴 연결 설정이 없었어요"라고 해요.
3. Codex가 켜져 있어서 되돌릴 수 없으면 "Codex를 정상 종료한 뒤 다시 해 주세요"라고만 하고 아무것도 바꾸지 않아요. 앱은 Codex를 끄지 않아요.

**남는 것**은 Claude 플러그인과 앱 파일이에요. 앱 파일은 휴지통으로 옮기면 돼요. 플러그인까지 지우려면 Claude Code에서 따로 지워요.

앱을 지우거나 꺼도 Codex는 깨지지 않아요. 연결은 앱이 아니라 플러그인과 `codex-cua`가 맡으니까, 앱이 없어도 Codex는 평소처럼 켜지고 Claude도 붙어요. 앱을 끄면 상태 보기와 자동 정리만 멈춰요.

## 개인정보

- 기록과 진단 복사에는 화면, 요청 내용, 시크릿이 들어가지 않아요. 시각, 연결, 도구 이름, 성공 여부, 걸린 시간만 있어요. 이 맥 밖으로 보내지 않아요.
- 앱이 직접 인터넷을 쓰는 곳은 하루 한 번 GitHub 릴리스 목록을 읽는 것 하나예요. 토큰도 계정도 없이 읽고, 보내는 것은 고정된 이름표 하나뿐이에요. 플러그인을 받거나 갱신할 때는 Claude Code가, 연결을 설정할 때는 플러그인의 설치 스크립트가 필요한 것을 받아 와요. 앱은 그 결과의 한 줄 요약만 보여 줘요.
- 앱이 저장하는 것은 마지막 새 판 확인 시각과 결과, 이미 알린 새 판 번호, 메뉴 막대 아이콘 위치, 처음 켰을 때 로그인 항목을 등록했다는 표시뿐이고, `~/Library/Preferences/dev.chenjing.cua-bar.plist`에 있어요.

## 개발하는 사람에게

```bash
cd apps/cua-bar
swift build && swift test          # 화면이 있는 로그인 세션이 필요해요
./scripts/build-app.sh             # CUABar.app을 만들고 ad-hoc 서명해요
./scripts/build-app.sh --install   # ~/Applications에 넣어요
CUABAR_NOTARY_PROFILE=<프로필> ./scripts/package-release.sh   # dist/에 서명·공증한 dmg와 SHA256SUMS.txt를 만들어요
./scripts/build-download-site.sh   # dist/의 판으로 download/public/과 download/release.json을 만들어요
(cd download && wrangler deploy)   # cua.chenjing.org에 올려요
```

- `build-app.sh`는 언제나 hardened runtime으로 서명해서, 손으로 깐 앱도 릴리스와 같은 규칙으로 돌아요. 예외는 Apple Events 하나예요(`scripts/CUABar.entitlements`). Codex 다시 켜기가 osascript로 Codex에 종료를 요청하기 때문이에요. `CUABAR_CODE_SIGN_IDENTITY`를 주면 그 신원으로 서명하고 보안 타임스탬프를 붙여요.
- `--install`은 있던 앱과 설정을 `~/Library/Application Support/CUABar/Backups/<시각>/`에 백업하고, 앱이 켜져 있으면 멈추고, 복사본의 서명을 확인한 뒤에 바꿔요.
- `package-release.sh [폴더]`는 키체인의 Developer ID Application 인증서로 앱을 만들어요(여럿이면 `CUABAR_CODE_SIGN_IDENTITY`로 골라요). `CUABAR_NOTARY_PROFILE`은 `xcrun notarytool store-credentials`로 만든 프로필 이름이에요. 앱을 공증받아 티켓을 붙이고, 그 앱을 담은 `CUABar-v<판>-macos-arm64.dmg`도 서명·공증해 티켓을 붙인 뒤 `SHA256SUMS.txt`와 함께 폴더에 써요. 기본 폴더는 `apps/cua-bar/dist/`이고 git이 보지 않아요. 합, dmg와 그 안 앱의 서명·티켓, Gatekeeper가 둘 다 받아들이는지까지 확인한 뒤, 태그 `cua-bar--v<판>`과 실행할 `gh release create ...` 명령을 **출력만** 해요. 태그를 만들거나 올리거나 `gh`를 부르지 않아요. 올리는 것은 그때그때 물어보고 직접 해요.
- `download/`는 cua.chenjing.org를 맡는 Cloudflare Worker예요. dmg, `SHA256SUMS.txt`, `install.sh`는 정적 파일로 나가고, `worker.js`가 첫 화면, `/download`(dmg로 넘김), `/install`(에이전트가 읽는 안내), `/version`(`install.sh`가 읽는 판 정보)을 답해요. `public/`과 `release.json`은 `build-download-site.sh`가 만들고 git이 보지 않아요. 릴리스마다 `package-release.sh` → GitHub 릴리스 → `build-download-site.sh` → `wrangler deploy` 순서로 올리고, 올리는 것은 그때그때 물어봐요.
- 앱 판 번호는 `plugins/cua/.claude-plugin/plugin.json`의 `version`에서 와요.
