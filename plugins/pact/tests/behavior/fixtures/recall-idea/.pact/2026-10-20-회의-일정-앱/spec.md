# 회의 일정 앱
## 목적
팀 회의 일정을 잡는 웹앱
## 범위
우리 팀 열 명이 쓰는 웹 화면 하나
## 하지 않는 것
- 다음 판 후보: 참석자 투표, 시간대 바꿔 보기
## 기능
- F1 달력 보기 [사용자]
  - 케이스: 같은 시간에 회의가 둘 → 겹침 표시
- F2 알림 보내기 [사용자]
  - 케이스: 알림을 못 보냄 → 화면에 실패 표시
## 검수 기준
- A1 달력에서 이번 주 회의를 한눈에 본다 [사용자]
## 구조 판정
화면 하나
## 확인 필요
- 알림을 메일로 보낼지 정하지 못함
