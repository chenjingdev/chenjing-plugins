# vet 벤치 프로토콜 — 실행·채점·기록 (FR-018 · SC-001 · I-10 · I-11)

## 전제
- `items.md` 상태가 **확정**(저자 검수 완료)일 것. 초안 상태로 실행 금지.
- 실행 창: Fable 접근 소멸 전, 저자 수동 1회 (자동 CI 아님).
- 두 arm은 같은 저장소, 같은 작업 디렉터리에서 실행한다 — 차이는 모델과 게이트 유무뿐.

## Arm 정의 (I-10)
- **vet arm**: 세션 모델 opus인 세션에서 `/vet <질문>` — 초안 opus + 검증자 opus 3 (+수정 시 재검증 3).
  env `CLAUDE_CODE_SUBAGENT_MODEL=opus`는 그대로 두어도 된다(검증자도 opus라 무해).
- **기준선**: 세션 모델 `claude-fable-5`인 세션에서 같은 질문을 **그대로**(/vet 없이, 게이트 없음) 1회 질문.
  도구 사용은 세션 재량에 맡긴다(실사용 Fable의 자연스러운 동작이 기준선).

## 실행 절차 (문항마다)
1. vet arm: 새 opus 세션 → `/vet <질문 원문>` → 최종 답변·수정 내역·검증 비용(stats)을 기록.
   부수 지표용으로 **초안**(수정 전)도 함께 저장해 둔다.
2. 기준선: 새 claude-fable-5 세션 → 질문 원문 그대로 → 답변 기록.
3. 세션을 문항마다 새로 연다(문항 간 오염 방지).

## 채점 (I-11 — 판단이 아니라 확인)
- 답변을 정답 키 항목별로 **일치 / 모순 / 무언급** 3분류한다.
- **모순 항목 수 = 그 답변의 확정 오류 수.** 무언급(누락)은 오류가 아니며 별도 기록한다.
- 채점 주체 = 저자가 정답 키와 수동 대조. vet 자신의 검증자나 제3 LLM으로 채점 금지(순환·주관성).
- 두 arm에 같은 정답 키를 동일하게 적용한다(분해 주관성을 정답 키가 흡수).

## 판정 (SC-001)
- 총합: vet arm 확정 오류 합계 ≤ 기준선 확정 오류 합계 → SC-001 충족.
- 문항별 표와 총합을 둘 다 보고한다.
- 부수 지표: vet 내부 초안 오류 수 → 최종 오류 수 감소량(게이트 자체의 기여).
- 비용 실측(호출 수·소요)을 함께 기록해 "예상 Opus ×2~4"를 사후 보정한다 (I-9 — "같은 가격" 슬로건 폐기, 실측이 정본).
