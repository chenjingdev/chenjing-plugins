# B7 (버그 사냥 recall) 채점 프로토콜 — 동결 2026-07-07

## 목적
판별력 있는 축 실측: 커버리지. 단일 패스 vs 독립 다중 패스 합집합 vs vet 파이프라인 vs Fable.
제품 주장("구조화 opus ×N ≥ Fable ×1")을 recall 숫자로 정면 측정.

## 팔 (5)
- fable-b7: Fable 1패스
- opus-b7-a/b/c: opus 1패스 ×3 (동일 프롬프트, 독립 세션 — 합집합 곡선용)
- vet-b7: /fableus:vet 파이프라인 (opus)
모든 팔 훅 배포 상태(규칙 1~5), 팔별 픽스처 사본, 동일 감사 프롬프트.

## 채점 규칙 (저자 수동 대조, 제3 LLM 산문 채점 금지 — vet bench FR-018 준용)
- 매칭: 보고된 발견 ↔ 정답 키 버그. 기준 = 같은 파일의 같은 결함 메커니즘 지목
  (라인 오차 허용, 증상만 맞고 메커니즘 다르면 불인정).
- recall = 매칭된 키 버그 수 / 12. 부분 인정 없음(원자 단위).
- precision 보조 지표: 키 밖 보고 중 (a) 실제 버그(저자 실측로 확인되면 "보너스 진짜" —
  키 결함으로 별도 기록) (b) 오탐(실측 불가·스타일 지적) 구분.
- 합집합 곡선: opus a → a∪b → a∪b∪c 순서로 한계 수확 기록 (순서는 a,b,c 고정 —
  사후 선택 편향 방지).

## 판정 기준 (사전 등록)
- 주장 1 "다중 패스가 값을 한다": recall(a∪b∪c) > recall(a) 이면 성립. 한계 수확이
  0이면 기각.
- 주장 2 "구조화 opus ≥ Fable": recall(a∪b∪c) ≥ recall(fable) 이면 성립.
- 주장 3 "vet 게이트가 1패스보다 낫다": recall(vet) > median(recall(a),(b),(c)) 이면 성립.
- 비용은 모든 판정에 병기 (달러/판).

## 개선 환류 (벤치 후)
가장 큰 차이가 난 지점의 구조를 플러그인 기능으로 흡수한다. 후보:
- 합집합 우세 → N-파인더 합집합+중복제거 스킬 (/fableus:sweep)
- vet 열세/오탐 → vet 렌즈·재검증 보강
- 특정 버그 분류 전멸 → 훅/스킬에 해당 클래스 실측 지시 추가
