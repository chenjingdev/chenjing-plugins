# recall

쌓인 기억에서 예전 시도와 그 끝, 실패와 원인, 미룬 아이디어, 지키라는 규칙을 뽑아 준다. 출처는 기억 서버(Honcho)의 대화, `~/dev`의 pact 기록, Claude 메모리 파일 셋이다.

## 돌리는 법

이 스킬의 Base directory에서 두 단계 위가 recall 폴더다. 아래에서 `<recall>`이라고 쓴다.

```
node <recall>/scripts/recall.mjs <주제 낱말…> --project <지금 프로젝트 절대 경로>
```

주제 낱말은 사용자 말에서 결과물 이름과 기능 낱말을 2~5개 고른다. 조사를 뗀다("선택지를" → "선택지"). `--project`는 지금 작업 중인 프로젝트의 절대 경로다.

## 전하는 법

- 출력의 네 묶음(예전 시도와 그 끝 · 실패와 원인 · 미룬 아이디어 · 지키라는 규칙)을 줄을 빼거나 보태지 말고 쉬운 말로 전한다. 날짜와 출처, `비슷한 기록`·`다른 저장소` 표시는 남기고, 빈 묶음은 "없음"이라고 쓴다.
- 머리줄 아래에 `못 읽음` 줄이 있으면 어느 출처를 왜 못 읽었는지 한 줄로 알린다. 나머지 출처의 결과는 그대로 전한다.
- 파일을 만들지 않는다. 결과는 채팅에만 둔다.
- 다른 스킬이 불렀으면 요약하지 않고 출력 전체를 그대로 돌려준다.
