- **[decision] 스폰 실패 처리** — 나라면 이렇게 정한다: 실행자 스폰 실패 시 gate-report.md에 해당 라운드 이슈 결과는 남기지 않고(부분 결과 금지, Edge Case 준수) 실패 로그 항목만 기록.
