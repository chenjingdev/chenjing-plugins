# salvo (v0.8.1)

한 발은 짐작, 일제사격은 측정 — 이름이 담은 한 줄: 한 번의 실행은 짐작이지만, 여러 독립 실행을 코드로 병합하면 측정이 된다.
제1원칙: 메인 세션은 오케스트레이션만 한다 — 집계·판독은 코드와 워크플로우가.

병렬 실행 플랫폼(003 명세, 게이트 통과)이 존재하며, 이전 프리셋은 그 위에 재등록될 예정이다:

| 명령 | 하는 일 |
|---|---|
| `/salvo:salvo` | 단일 문. 요청을 신고서(intake form)로 라우팅 — 즉석 폼 작성(union/vote/pick 병합, 표 세기는 코드), 위임(1회 실행 = "단일 실행 — 교차 검증 없음"), 스펙 요청은 공지 후 /spec:spec 자동 호출, 못 채우면 반려. 실행 기록은 ~/.claude/plugins/data/salvo-chenjing-plugins/records/에 축적 (승격 증거) |

- `/spec:spec` · `/spec:spec-gate`(인터뷰 명세 작성 + 콜드 리더 관문)는 v0.8.0에서 별도 `spec` 플러그인으로 분리되었다 (breaking). 스펙 요청은 이 문이 공지 한 줄 후 `/spec:spec`을 자동 호출한다(미설치 시 안내만). 패키징(활성화)만 분리, 런타임 인계는 유지 (D-9).
- 상시 주입 훅은 없다 (의도적으로 뺌 — 이름과 훅은 세션을 조건화하는 토큰이므로).
- 이전 프리셋(vet · sweep · leg)과 새 프리셋(분할 · 갈림 감지 · 평문 인계 등)은
  003 플랫폼 위 프리셋(intake-form.json + skill 래퍼)으로 재등록될 예정.
