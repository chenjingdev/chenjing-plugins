# salvo (v0.5.2 — 재조립 중)

한 발은 짐작, 일제사격은 측정.
제1원칙: 메인 세션은 오케스트레이션만 한다 — 집계·판독은 코드와 워크플로우가.

2026-07-08 백지화 이후 재조립 중이다. 검증된 두 무기만 우선 복원했다:

| 명령 | 하는 일 |
|---|---|
| `/salvo:spec` | 러프한 아이디어를 인터뷰로 파고들어 구현 가능한 명세(SPEC.md)로 만든다. 완성되면 관문이 자동 발동 |
| `/salvo:spec-gate` | 콜드 리더 N명(기본 3, 무맥락·무도구)을 워크플로우 하나로 병렬 발사 — 출력은 schema로 강제, 2표 이상 겹침(앵커+범주 일치)은 스크립트가 셈. 확정 0이면 통과, 아니면 피드백 반영 후 다음 라운드 자동 시작 |

- 상시 주입 훅은 없다 (의도적으로 뺌 — 이름과 훅은 세션을 조건화하는 토큰이므로).
- 이전 무기(vet · sweep · leg)와 새 무기(분할 · 갈림 감지 · 평문 인계 등)는
  C안 — 계약 우선, 존재론 사후 — 에 따라 신고서(다섯 칸 + 정의 하나 + 잔여 밸브)를 갖춰 재등록 예정.
- 백지화 이전 전체 이력: git `19f343d`(v0.4.0)까지, 산출물 보존 스냅숏은 `845cc51`.
